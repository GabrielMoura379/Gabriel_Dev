GABRIEL DEVS — SITE INSTITUCIONAL
=================================

Arquivos:
- index.html: estrutura da página
- style.css: layout, responsividade e animações
- script.js: menu mobile, filtro de projetos, modais e formulário WhatsApp

Como visualizar:
1. Extraia o ZIP.
2. Abra index.html no navegador.

Como publicar gratuitamente no GitHub Pages:
1. Crie um repositório no GitHub.
2. Envie index.html, style.css e script.js para a raiz.
3. Vá em Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch e escolha main / root.
5. Salve e aguarde a URL de publicação.

Personalização:
- O número de WhatsApp está no início de script.js (formato internacional, somente números).
- Os projetos da página estão identificados como conceitos demonstrativos.
- Os links de Instagram e os dados de contato estão no index.html.
- O site não inclui backend; o formulário abre uma conversa do WhatsApp com a mensagem preenchida.
